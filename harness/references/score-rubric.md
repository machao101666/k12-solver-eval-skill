# Score Rubric

## 待测模型评分

- 输入：原题图片、学段、学科、题型、AC 伪标签、AF 待测模型完整输出。
- 输出：AI 待测模型 score_0_3，AJ judge_reason。
- 完整流水线中 AF 来自 Stage 6 的待测模型输出；现有解题集独立模式中，AF 来自指定结果 JSONL。
- 3 分结构化格式只认可按顺序、原样出现 `==**解题过程**==` 和 `==**最终答案**==`；格式不符最高 2 分，其他答案与推理规则不变。该格式要求由 `config.yaml` 的 `evaluation.required_output_headings` 定义，改动必须同步 `prompts/stage7_score_target.md`。

## 五模型横向评分

- 输入：原题图片、学段、学科、题型、AC 伪标签、对应模型 Reasoning + Answer。
- 输出：AK-AT。
- 使用 `prompts/stage7_score_reference.md` 中的参考模型评分提示词。

## 分数含义

- 0：完全不可用。
- 1：基本不可用。
- 2：核心可用。
- 3：完全可用。

## 强规则

- 任一关键输入字段为空，直接 0 分。
- 只有推理无最终答案，直接 0 分。
- 开放题不按唯一标准答案卡死，但必须有明确观点/结论。
- 3 分门槛严格，存在轻微不严谨、跳步、表述随意等情况最高 2 分。

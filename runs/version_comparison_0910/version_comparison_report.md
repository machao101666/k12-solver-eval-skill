跨版本横向对比报告（各版本前 3 次重复，裁判 OneAPI Opus 5）

> 评测集：161 道 confidence=high｜裁判：OneAPI `Opus 5`｜每版本重复 3 次

# 结论摘要

1. **≥2分率三版本高度接近**（均在 90~92%，两两差距小于单次 ±2pp 波动），用 3 次样本无法区分合格率高低。真正的差异体现在 3分率（优质率）。
2. **3分率最高：v0.1.1.0 (L20 tp2)（65.0%）；最低：v0.1.2.0 (L20 tp2)（51.8%）**，两者相差 13.3pp，超出波动幅度。
3. **v0.1.1.0 → v0.1.2.0 优质率明显回落**：3分率从 65.0% 降到 51.8%（-13.3pp），但 ≥2分率基本持平（91.7% vs 90.3%）。说明合格能力没退，是更多题从 3 分掉到 2 分——需结合第三章看是风格还是答案错误。
4. **v0.0.9.4 (H100 tp2x2)** ≥2分率 92.3%、3分率 58.6%，介于两个新版本之间，可作为旧版本基线参考。
5. **仅 3 次重复，结论为趋势性**：如需定论，建议每版本补齐到 9 次取均值。

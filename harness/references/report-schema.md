# Report Schema

Stage 8 生成 Markdown 报告，默认输出到 run 目录的 `report.md`。

## 报告章节

1. 核心指标汇总与结论
2. 一、高置信题集概览
3. 二、待测模型评分结果（2.1 整体评分指标、2.2 分学段 × 学科、2.3 分题型 2+ 分率、2.4 待测模型耗时、2.5 低分题清单）
4. 三、解题模型横向评分

## 不生成

- 不生成“五、自动优化建议”。

## 统计口径

- 主指标：2+分率，即 score >= 2（达标线见 `config.yaml` 的 `evaluation.pass_score`）。
- 风险指标：0分率、1分率。
- 优质率：3分率。
- 入集率：confidence=high / 候选题总数。
- 横向评分：待测模型 + 参考模型，按 Excel 实际评分列计算，不是固定模型清单。待测模型取 AI 列，五个参考模型取 AK/AM/AO/AQ/AS 列；某个模型的评分列不存在或全为空时，该模型不出现在横向评分表中。
- 横向评分来源默认是主输入 Excel，可用 `--cross-model-xlsx` 指定其他 Excel。

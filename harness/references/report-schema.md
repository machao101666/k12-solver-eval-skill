# Report Schema

Stage 8 生成 Markdown 报告，默认输出到 run 目录的 `report.md`。

## 报告章节

1. 核心指标汇总与结论
2. 一、候选题集概览
3. 二、多模型解题与共识入集
4. 三、待测模型评分结果
5. 四、解题模型横向评分
6. 4.1 横向评分低分题清单

## 不生成

- 不生成“五、自动优化建议”。

## 统计口径

- 主指标：2+分率，即 score >= 2。
- 风险指标：0分率、1分率。
- 优质率：3分率。
- 入集率：confidence=high / 候选题总数。
- 横向评分：小度 + 五个参考模型。
